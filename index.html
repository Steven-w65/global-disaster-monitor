Using the monitor

Pan and zoom the map, then click a marker for details. Use the source, type, and time controls to narrow the view. Refresh feeds manually or wait for the ten-minute update. Use the header theme button to switch light/dark.

Data providers

NASA EONET tracks natural events, USGS provides recent earthquakes, and GDACS UN adds international alerts. Each feed is displayed independently.
